# Лабораторная работа № 3. Формирование проектных команд

Вариант **14**, seed **10031**. Три команды из 12 кандидатов с ограничениями по ролям, совместимости и рабочим часам. Основное решение использует MILP. Выполнены LP-релаксация, сценарии, сравнение с жадным методом, эксперимент с big-M и сравнение эквивалентных формулировок.

## Воспроизведение

Проверено на Python **3.13.15** и HiGHS **1.12.0**, включённом в установленную сборку SciPy **1.18.1**. Из корня проекта выполните:

```powershell
python -m pip install -r Lab3/requirements.txt
python Lab3/run.py
```

`run.py` читает готовые входные JSON. Команда выполняет все эксперименты, проверяет решения и обновляет отчёт и таблицы в `Lab3/outputs`. Папка результатов определяется по расположению скрипта, поэтому из `Lab3` можно запустить `python run.py`. Значения времени при повторном запуске будут отличаться.

## Данные

`data/teams_12.json` содержит исходный вариант и сценарии. `data/teams_24.json` и `data/teams_48.json` используются для эксперимента с ростом размера. Все данные синтетические.

Команда `python Lab3/generate_data.py` воспроизводит и перезаписывает эти три файла. Для каждого размера создаётся отдельный поток NumPy через `SeedSequence([10031, размер])`. Роли назначаются циклически. Часы кандидатов выбираются из целых 5–10, оценки совместимости с проектом из целых 42–85. Три исходных кандидата каждого проекта получают по 8 дополнительных баллов по этому проекту. Пары разных ролей включаются в список несовместимых с вероятностью 0,17, кроме пар внутри исходной тройки. Лимиты резерва, его стоимость, потребность в часах и сценарии заданы явно.
