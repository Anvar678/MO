# Лабораторная работа № 1: смешение углей для ТЭС

Вариант 14, seed 10031. Вариант должен быть подтверждён преподавателем: по методичке он вычисляется из номера студента, индекса группы и года. Данные учебные, а не реальные данные ТЭС.

## Установка и запуск

В PowerShell из папки `Lab1` (проверено на Python 3.13.15):

```powershell
python -m pip install -r requirements.txt
$env:PYTHONIOENCODING = 'utf-8'
$env:MPLBACKEND = 'Agg'
python run.py
```

Одна команда `python run.py` читает `data/coal_data.json`, решает модель и записывает результаты в `lab1_outputs/`. Код использует SciPy/HiGHS, проверяет решение отдельно на NumPy и не изменяет исходные данные. Для повторной генерации входного файла отдельно запустите `python generate_data.py`: он перезапишет JSON. Программа задаёт исходные массивы и добавляет к ним случайные отклонения NumPy с seed 10031; конкретные диапазоны приведены в коде генератора.

## Состав

- `run.py` — расчёт, сценарии, независимая проверка и формирование отчёта.
- `data/coal_data.json` и `generate_data.py` — данные и процедура генерации.
- `lab1_outputs/report.md` — отчёт; `solution.csv`, `scenarios.csv`, `scenario_plans.csv` — результаты.
- `verification.csv`, `scenario_verification.csv` — независимая проверка; `shadow_comparison.csv` — сравнение теневых оценок с повторным решением; `methods.csv` — дополнительное сравнение алгоритмов.
- `solver.log` — протокол статусов и итераций, полученных через SciPy; это не нативный подробный лог HiGHS. PNG-файлы содержат графики.
- `Lab1.ipynb` — исходная версия пояснений, сохранена для справки; основной воспроизводимый комплект — скрипт и JSON, так как блокнот генерирует данные самостоятельно и требует Jupyter и tabulate.

Время сравнения методов зависит от компьютера и условий запуска. Данные и модель упрощены: не учитываются теплота сгорания, влажность, перевозка и условия контрактов.
