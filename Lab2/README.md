# Лабораторная работа № 2 — балансировка такси

Вариант 14, seed 10031. Учебная модель сети из восьми зон: перераспределение свободных автомобилей из зон избытка в зоны спроса с минимальной стоимостью.

## Установка и запуск

Проверено на Python 3.13.15. В PowerShell из папки Lab2:

```powershell
python -m pip install -r requirements.txt
python run.py
```

Одна команда `python run.py` читает `data/taxi.json` и создаёт отчёт, таблицы, протокол и схему в `outputs/`. Данные и модель разделены. Для повторной генерации учебных данных выполните `python generate_data.py`: эта команда перезапишет JSON. Стоимости формируются на основе условного расстояния между зонами и случайной добавки с seed 10031; балансы, координаты и ёмкости заданы в генераторе. Данные не являются реальными наблюдениями.

## Файлы

- `data/taxi.json` — вершины, балансы, дуги, их стоимость и пропускная способность.
- `run.py` — решение SciPy/HiGHS, независимая проверка, сценарии, эвристика и целочисленное расширение.
- `outputs/report.md` — постановка, формальная модель, результаты и выводы.
- `outputs/network.png` — схема с потоками и пропускными способностями.
- `outputs/solution.csv`, `scenarios.csv`, `plan_*.csv` — решение и планы допустимых сценариев.
- `verification_nodes.csv`, `verification_scenarios.csv` — результаты независимой проверки; нарушения границ каждой дуги находятся в `solution.csv`.
- `shadow_prices.csv`, `greedy.csv`, `integer_comparison.csv`, `integer_plan.csv` — проверка теневых оценок, сравнение с эвристикой и результаты дополнительной целочисленной модели.
- `solver.log` — нативный вывод HiGHS 1.12.0 и сводка сценариев.

При росте спроса на 20% задача несовместна: машин меньше, чем спроса. Реальные тарифы, водители, пробки, динамика спроса и время поездок в упрощённой модели не учитываются.
