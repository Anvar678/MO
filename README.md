# Методы оптимизации

Лабораторные работы по линейному программированию. Лабораторная работа № 1 выполнена в Jupyter Notebook для варианта 14 (seed 10031); для решения используется `scipy.optimize.linprog` с методом HiGHS.

Для запуска блокнота установите Python и зависимости:

```powershell
python -m pip install jupyter numpy pandas scipy matplotlib
jupyter notebook
```

Откройте `MOLab1_Variant14_seed10031_Yangirov.ipynb` и выполните все ячейки. Результаты сохраняются в папку `lab1_outputs`.

Сейчас блокнот и файл методических материалов исключены из Git правилами в `.gitignore`.
